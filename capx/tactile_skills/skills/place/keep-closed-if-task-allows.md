## How

Read what the task check actually measures before adding a release to the end of
it. In these scenes a placement is scored on the object's resting pose, and the
check never asks that the jaws be open — seat the object on the support and
stop there, still holding it.

## Traps

- **Opening is a motion, not a formality.** The jaws retract past the object,
  and a tall object on a narrow footprint is dragged or tipped by that motion
  rather than left standing. A release also costs a re-approach, which is
  where grasp accuracy is lost ([[one-call-approach]]).
- Once released, the object is somewhere new, so every reading taken afterwards
  describes a different grasp than the one the judgement was made from
  ([[preserve-existing-grasp]]).
- The exception is real: when the check requires the hand clear, or the task
  scores a reading that only exists after the object has been set down, the
  release is part of the task and wants the full placement recipe
  ([[unload-before-open]], [[settle-after-release]]).
